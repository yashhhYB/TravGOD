⚡ Feature Specifications & Behaviors
Interactive Command Dashboard

Central interactive map displaying live markers for Paris. Filterable using category toggles: All, Guides, Hotels, Food, Attractions, Safety.

  • ✓ Search bar accepts destination input (e.g. Paris, Tokyo, Cairo) and updates map bounds.
  • ✓ Clicking a map marker opens a compact detail popover card with photo, title, rating & actions.
ScamSense & Fair Price Guidance

Curated Cards detailing common tourist scams (e.g., Gold Ring, String Bracelet) alongside a Fair Price Comparison widget.

  • ✓ Displays Scam Type, Location, Red Flags, and Prevention tips.
  • ✓ Displays comparison ranges: Tourist Trap Price vs. Expected Fair Local Price.
Verified Guide Directory & AI LocalMatch

Grid of local guide profiles with language tags, hourly rates ($25/hr), glowing "Verified Local" badges, and AI match scoring.

  • ✓ Filters by spoken language (English, Spanish, French, etc.) and hourly price.
  • ✓ AI LocalMatch computes ranking (e.g. "96% Match") and outputs clear match rationale.
Free Chat & AI Translation

Instant messaging container before and after booking, featuring quick prompt chips and automatic AI translation.

  • ✓ Free messaging allows pre-booking inquiries without requiring payment first.
  • ✓ AI Translation toggle translates incoming messages with "Show Original Text" option.
PayPal Checkout & Booking Lifecycle

Full end-to-end checkout with PayPal Sandbox integration and immediate booking confirmation screen.

  • ✓ Shows itemized Booking Summary (Date, Time, Hours, Rate $25/hr, Total).
  • ✓ Successful PayPal checkout opens Booking Confirmed screen with reference code (RM-89421-PAR).
  • ✓ Saves confirmed booking into My Trips management tab.
Empty States & Recovery Paths

Graceful handling of unserved languages or unavailable time slots.

  • ✓ Searching for unserved language (e.g. Icelandic in Paris) renders friendly empty state: "No verified Icelandic-speaking guides available in Paris."
  • ✓ Provides immediate alternative recovery options: "Show 12 English-speaking guides" or "Notify me".
